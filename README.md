# Prana-health-resilience
PRANA (Privacy-preserving Resilience & Adaptive Neural Assistant) is an AI-powered personalized environmental health monitoring system.

Integrates physiological, environmental, and behavioural data to assess individual health risks.
Establishes a personal health baseline and detects deviations from the user's normal condition.
Generates personalized risk scores and preventive recommendations based on current environmental conditions.
Provides a Disaster Resilience Mode for situations such as heatwaves, high pollution, and extreme weather.
Uses a privacy-first, edge-oriented approach to minimize unnecessary sharing of sensitive health data.
